# 面向电力政策推演的可复现知识图谱构建与评测框架

## 摘要
政策文本天然具备高价值治理信息，但其非结构化、跨文档异构和口径不一致等特征，使得传统人工研读与简单检索难以支持系统性政策推演。本文提出一套面向电力与电能替代政策场景的端到端知识图谱方法框架，覆盖 Schema 设计、抽样标注、预处理切分、抽取归一化、多人双盲评测、图包导出以及 Neo4j 落地评测全流程。方法上，本文强调“可入图、可追溯、可复现”三项工程约束：通过 UIE + 规则后处理 + 两阶段重绑定实现可计算结构化；通过固定分母指标、多标注者双盲 IAA 与硬错误桶门禁实现稳定评测；通过双轨图包（strict_high/strict_all）与确定性重放实现可复跑交付。实验结果显示：Step4 可导入评分由 39.482 提升至 76.332；Step7 阶段 `strict_high_on_valid_numeric` 达 0.850760，机制精度达 0.957597，归一化精度达 1.000000；Step8 `deterministic_replay_match=true`；Step9 在 Neo4j 侧实现 `query_execution_success_rate=1.0`、`traceability_rate=1.0` 且总门禁通过。结果表明，该框架可作为政策图谱工程化与论文复现实验的一体化技术底座。

**关键词**：政策知识图谱；信息抽取；归一化；多人标注；Neo4j；可复现评测

---

## 1. 引言

### 1.1 研究背景
在电力市场改革、分时电价调整、清洁取暖和电能替代政策持续推进的背景下，政策文本数量快速增长。政策评估与推演任务越来越依赖跨文档、多层级、强时效的结构化知识支持。然而，现有工作在实际落地时通常面临三个问题：
- 抽取结果“能看不能算”：字段命中但难以稳定形成图结构；
- 评测结果“可比性弱”：不同迭代口径漂移导致结论不稳；
- 工程成果“难复现”：缺少可核验的数据包、门禁和重放机制。

### 1.2 研究目标
本文目标不是提出新的大模型，而是构建一套可复现、可审计、可推演的政策知识图谱工程方法，回答以下问题：
1. 如何将政策文本稳定转化为可入图三元组并保留证据链；
2. 如何建立跨迭代、跨标注轮次可比较的质量评价体系；
3. 如何从离线抽取结果走向 Neo4j 端到端可查询、可评测的应用闭环。

### 1.3 主要贡献
1. 提出面向“可入图”的抽取与归一化流程：UIE 抽取与规则后处理结合，两阶段机制重绑定提升结构可计算性。  
2. 提出固定分母 + 多标注者双盲 IAA + 硬错误桶门禁的评测方法学，显著降低指标漂移风险。  
3. 提出双轨图包与确定性重放机制，并完成 Neo4j 导入、查询、推演的端到端闭环验证。

## 2. 相关工作

### 2.1 政策文本结构化与信息抽取
政策文本抽取通常依赖规则模板、监督学习或大模型提示。规则方法可解释但泛化弱，纯模型方法召回较高但一致性与可审计性不足。本文采用“模型抽取 + 规则补强”的工程折中：把优化目标从单字段命中率转移为“可入图三元组就绪率”。

### 2.2 知识图谱工程化
多数图谱构建工作聚焦实体关系抽取，对“证据回溯、口径固定、可重放交付”关注不足。本文在流程级引入 offset 审计链、门禁报告与 manifest 哈希，强化工程复现实验能力。

### 2.3 图检索与推演应用
图查询框架在多跳检索和关系解释方面有优势，但高质量应用依赖稳定图数据和风险信号。本文将冲突信号直接附着于边，并在 Step9 进行风险感知重排非退化验证。

## 4. 方法

### 4.1 Step1-3：Schema、预处理与审计链

#### 4.1.1 全量语料驱动 Schema
Step1 不采用先验闭门设计，而是先全量读通、再按证据构造字段。Schema 覆盖政策元信息、机制类型、参数定义与参数提及，并明确 `ParameterDefinition` 与 `ParameterMention` 分离建模，确保后续同值归并与证据追踪并存。

#### 4.1.2 汇总文本拆分与条款切分
Step3 对汇总拼接文本按 `<h2>file:` 先拆成文档单元，再进行编号规则切分、标点切分、超长再切和表格兜底切分。条款最大长度约束为 400，兼顾上下文完整度与模型输入稳定性。

#### 4.1.3 clean/raw 双向 offset
通过 `clean_to_raw` / `raw_to_clean` 映射和 roundtrip 校验，建立从结构化结果回溯到原文字符位置的审计链。Step3 结果显示 mismatch 为 0、非法 span 为 0。

### 4.2 Step4-5：抽取、归一化与两阶段重绑定

#### 4.2.1 UIE 抽取 + 规则后处理
Step4 使用 PaddleNLP `Taskflow("information_extraction")` 执行文档级和条款级抽取。随后通过后处理补齐：
- `clause_type` 回填；
- `mechanism_type` 规则补强；
- 参数值/单位正则补抽；
- 任务型字段补抽（主体、动作、期限、考核）。

该设计核心是“可入图优先”：优化目标面向可计算三元组，不是单条字段命中。

#### 4.2.2 归一化与机制重绑定
Step5 引入固定分母体系（`all_clause`、`valid_all`、`valid_numeric`）并执行两阶段重绑定：
1. clause 级候选评分（位置、关键词、参数先验、继承信号）；
2. mention 级机制绑定决策（含负域守卫与置信度上限）。

同时执行参数归一化（百分比、金额、单位别名、时间窗、阈值区间等），并区分 `strict_all` 与 `strict_high` 两轨输出。

### 4.3 Step6-7：双盲 IAA 与联合门禁

#### 4.3.1 多标注者双盲流程
Step6 在固定样本计划下执行 Pass-A / Pass-B 双盲标注及仲裁，计算 `kappa`、精度与硬错误桶指标。

#### 4.3.2 Step7 小样本增量优化
在不改变主流程的前提下，修复单位错配与时间参数语义对齐问题；通过 Step5（抽取质量）+ Step6（Gold/IAA）联合门禁防止“提覆盖降精度”。

### 4.4 Step8-9：双轨图包与 Neo4j 闭环

#### 4.4.1 双轨图包
Step8 输出 `strict_high`（高置信主图）与 `strict_all`（扩展召回图），附带 `manifest`、`stats`、`rejects`、`conflicts` 等审计文件。

#### 4.4.2 冲突信号化与查询模板
Step8.2 构建 `query_pack.cql`、`query_examples.json` 与 `edge_signals.csv`，将冲突统计映射为边级特征，形成可执行查询与风险信号入口。

#### 4.4.3 Neo4j 导入与门禁
Step9 在 Neo4j 5.26.0 社区版上完成导入、索引约束、查询评测和推演案例集输出，并通过总门禁验证端到端可用性。

## 5. 实验设置

### 5.1 实验环境与工具链
- 语言：Python 3.12  
- 图数据库：Neo4j 5.26.0-community  
- 抽取组件：PaddleNLP Taskflow（UIE）  
- 主要脚本：
  - Step4：`00_整理记录/scripts/run_step4_uie_baseline.py`
  - Step5：`00_整理记录/scripts/run_step5_normalize_validate.py`
  - Step6：`00_整理记录/scripts/run_step6_gold_iaa.py`
  - Step8：`00_整理记录/scripts/run_step8_export_graph.py`
  - Step9：`00_整理记录/scripts/run_step9_neo4j_eval.py`、`run_step9_query_eval.py`、`run_step9_simulation.py`

### 5.2 指标体系
1. 可入图可用性：`total_score`、`strict_triplet_ready_rate`、`param_bind_rate`。  
2. 归一化与绑定质量：`normalization_matched_rate`、`mechanism_bound_rate_valid_numeric`、`strict_high_rate_valid_numeric`。  
3. 多人标注一致性：`kappa_mechanism`、`kappa_param_type`、`exact_match_norm_unit`。  
4. 图工程与落地：`deterministic_replay_match`、`traceability_rate`、`query_execution_success_rate`、`core_path_coverage`。

### 5.3 门禁策略
每阶段设置定量门槛并输出 `all_targets_passed`。核心原则：
- 不允许通过改变分母定义“制造提升”；
- 硬错误桶（如时间窗误判、价格数量级错误）必须归零；
- 导出包必须通过 schema/fk/pk/单位/证据与重放一致性验证。

## 8. 局限性与伦理说明

### 8.1 局限性
1. 本文为工程方法论文，尚未提供跨领域外部数据集泛化实验。  
2. 图谱聚焦政策文本结构信息，不直接包含宏观时序统计（如地区电量年度曲线），相关因果推演需外部数据融合。  
3. 风险感知重排在当前案例集中表现为“非退化”，但改进幅度受候选池分布影响。

### 8.2 伦理与使用边界
1. 推演输出用于决策支持，不应替代监管/法律最终判定。  
2. 对外发布需同步披露数据来源、处理流程与适用边界。  
3. 对敏感场景建议保留人工复核环节，避免自动化误导。

## 9. 结论与未来工作
本文提出并验证了一套面向电力政策推演的知识图谱工程框架，核心在于：  
1. 以“可入图、可追溯、可复现”为目标重构抽取与归一化流程；  
2. 以固定分母、双盲 IAA 和门禁化评测确保结果可信；  
3. 以双轨图包和 Neo4j 端到端闭环实现可部署应用。

实证结果表明，该框架在抽取质量、评测稳定性和工程落地能力方面均达到可发布水平。下一步将重点开展跨省域泛化评测、外部时序数据融合及多轮推演代理策略优化。
