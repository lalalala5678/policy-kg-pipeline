# 数据开放与复现边界声明

## 1. 可公开内容
1. 代码与脚本：`00_整理记录/scripts` 下的构建、评测、门禁、导出与复现实验脚本。  
2. 结构化中间产物与评测报告：Step3-Clause 语料、Step4-9 各阶段 JSON/JSONL 报告、Step12/14/15/16/17/18/19 补充报告。  
3. 图包与审计材料：`manifest.json`、`validation_report.json`、`stats.json`、`query_pack.cql`、`query_examples.json`、`edge_signals.csv`。  
4. 复现实验表格资产：`结果文件夹/投稿版图表包`。

## 2. 受限或需谨慎公开内容
1. 原始政策文本全集（若含第三方平台聚合来源、格式化副本或版权不明文件）建议仅提供文件清单与哈希，不直接二次分发原文副本。  
2. 任何包含账号、密码、API Key、服务器公网地址等运维敏感信息的配置文件不得公开。  
3. 若后续接入企业内部文档、非公开政策草案或人工标注身份信息，需先完成脱敏与授权审查。

## 4. 复现实验结论的执行路径
1. 先运行 Step8/Step9 的导入与查询门禁命令，确认 `all_targets_passed=true`。  
2. 再运行 Step12/14/15/16/17/18/19 生成补充评测报告。  
3. 最后运行 Step13 生成投稿版图表包，与论文主文表格逐项对照。

## 5. 版本冻结建议
1. 论文提交版本固定 `git commit`，并在 `manifest` 与补充材料首页注明。  
2. 对所有关键 JSON/CSV 给出 `sha256`，避免“同名文件不同内容”。  
3. 若更新抽取规则或门禁阈值，必须增加新 run_id，不覆盖旧结果。
